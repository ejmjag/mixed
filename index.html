LESSON 01

Mixed Conditionals: Past → Present

Өткен жағдайдың қазіргі нәтижесі
If + Past Perfect, would/could/might + V1
SITUATION 1.1
If I had studied harder, I would have a better job now.
Егер бұрын жақсырақ оқығанымда, қазір жұмысым жақсырақ болар еді.
Өткендегі оқу өзгермейді, ал нәтиже қазір көрінеді.
SITUATION 1.2
If she had taken the train, she would be here now.
Егер ол пойызға мінгенде, қазір осында болар еді.
Өткен әрекет → қазіргі жағдай.
SITUATION 1.3
If I had saved money, I could buy a laptop now.
Егер ақша жинағанымда, қазір ноутбук сатып ала алар едім.
Could — қазіргі мүмкіндікті білдіреді.

Есте сақтаңыз

  • If-бөлігінде had + V3, нәтиже бөлігінде would + V1 қолданылады.
  • Would have + V3 болса, ол өткен нәтижеге жатады (Third Conditional).
  • Now, today, at present сөздері қазіргі нәтижені анықтауға көмектеседі.
Mini Quiz · If I ___ the medicine yesterday, I would feel better now.
LESSON 02

Mixed Conditionals: Present → Past

Қазіргі/тұрақты жағдайдың өткен нәтижесі
If + Past Simple, would/could/might have + V3
SITUATION 2.1
If I were more careful, I would not have lost my keys yesterday.
Егер мен ұқыптырақ адам болсам, кеше кілтімді жоғалтпас едім.
Тұрақты мінез → кешегі нәтиже.
SITUATION 2.2
If he spoke French, he could have helped them last week.
Егер ол французша сөйлей алса, өткен аптада оларға көмектесе алар еді.
Қазіргі дағды → өткен мүмкіндік.
SITUATION 2.3
If we lived closer, we would have attended the meeting yesterday.
Егер жақынырақ тұрсақ, кеше жиналысқа қатысар едік.
Қазіргі мекен → өткен нәтиже.

Есте сақтаңыз

  • Were барлық жақта ресми/емтихандық нұсқа ретінде қолданылады: If I were.
  • Нәтиже бөлігіндегі have + V3 өткен уақытты көрсетеді.
  • If I had been more careful — өткен себеп; If I were more careful — тұрақты қасиет.
Mini Quiz · If he were more organized, he ___ the deadline last week.
LESSON 03

Mixed vs Second vs Third

Үш түрдің мағыналық айырмасы
Second: past → would V1 · Third: had V3 → would have V3 · Mixed: уақыттары аралас
SITUATION 3.1
If I knew the answer, I would tell you.
Жауапты білсем, саған айтар едім.
Second: қазір → қазір.
SITUATION 3.2
If I had known the answer, I would have told you.
Жауапты білгенімде, саған айтар едім.
Third: өткен → өткен.
SITUATION 3.3
If I had known the answer, I would be confident now.
Жауапты бұрын білгенімде, қазір сенімді болар едім.
Mixed: өткен → қазір.

Есте сақтаңыз

  • Уақытты грамматикалық формаға қарап қана емес, сөйлем мағынасына қарап анықтаңыз.
  • If-бөлікте әдетте would қолданылмайды; ерекше сыпайы өтініш/ниет мағынасы бөлек.
Mini Quiz · If she had studied, she ___ a doctor now.
LESSON 04

Unless / If not

«Егер ... болмаса»
Unless + affirmative clause = if ... not
SITUATION 4.1
Unless you hurry, you will miss the bus.
Асықпасаң, автобусқа үлгермейсің.
Unless = if you do not hurry.
SITUATION 4.2
I will not go unless you come with me.
Сен менімен бірге бармасаң, мен бармаймын.
Болымсыз негізгі сөйлем болуы мүмкін.
SITUATION 4.3
Unless it rains, we will play outside.
Жаңбыр жаумаса, сыртта ойнаймыз.
Unless-тен кейін тағы not қою көбіне мағынаны өзгертеді.

Есте сақтаңыз

  • Unless шарт орындалмаса болатын нәтижені білдіреді.
  • If ... not барлық жағдайда unless-пен толық алмастырылмайды, әсіресе ерекше контрастта.
  • Unless you do not... түрі әдеттегі if not баламасы емес.
Mini Quiz · ___ you have a valid ticket, you cannot board.
LESSON 05

Provided / Providing / As long as / On condition that

Қатаң шарт және қажетті талап
Provided (that) / Providing (that) / As long as + Present Simple
SITUATION 5.1
You can borrow my laptop provided that you return it tonight.
Бүгін кешке қайтарсаң, ноутбугымды ала аласың.
Provided that — нақты талап.
SITUATION 5.2
As long as you work hard, you will improve.
Талмай еңбектенсең, жақсарасың.
As long as — шарт орындалған жағдайда.
SITUATION 5.3
They will agree on condition that we pay in advance.
Алдын ала төлесек қана олар келіседі.
On condition that — ресми шарт.

Есте сақтаңыз

  • As long as кейде уақыт ұзақтығын да білдіреді: as long as I live.
  • Болашақ мағынадағы шарттан кейін әдетте Present Simple қолданылады.
Mini Quiz · You can use the room ___ you clean it afterwards.
LESSON 06

In case vs If

Алдын ала сақтану және шарт
In case + clause = сақтық үшін; If + clause = шарт орындалса
SITUATION 6.1
Take an umbrella in case it rains.
Жаңбыр жауып қалуы мүмкін, сондықтан қолшатыр ал.
Қолшатырды алдын ала аласыз.
SITUATION 6.2
Take an umbrella if it rains.
Жаңбыр жауса, қолшатыр ал.
Әрекет жаңбыр жауған жағдайда болады.
SITUATION 6.3
I saved the file in case the computer crashed.
Компьютер істен шығып қалуы мүмкін деп файлды сақтадым.
Сақтық әрекеті алдын ала жасалды.

Есте сақтаңыз

  • In case of + noun: in case of fire (өрт болған жағдайда).
  • In case пен if бірдей емес: біріншісі — precaution, екіншісі — condition.
Mini Quiz · ___ the alarm goes off, leave the building.
LESSON 07

Even if / Even though

Нәтижені өзгертпейтін шарт
Even if + condition; Even though + fact
SITUATION 7.1
Even if it rains, we will go hiking.
Жаңбыр жауса да, жорыққа шығамыз.
Болуы мүмкін шарт шешімді өзгертпейді.
SITUATION 7.2
Even though it is raining, we are going out.
Қазір жаңбыр жауып тұрса да, сыртқа шығып жатырмыз.
Even though — нақты факт.
SITUATION 7.3
I would help you even if I were busy.
Бос болмасам да, саған көмектесер едім.
Болжамды кедергі.

Есте сақтаңыз

  • Even if — шарт/болжам; even though — белгілі факт.
  • Even if ... not мағынасын сөйлем контексіне қарап түсініңіз.
Mini Quiz · She went out ___ she was tired.
LESSON 08

Only if / If only

Қажетті шарт және өкініш
Only if = тек ... жағдайда; If only = шіркін / әттең
SITUATION 8.1
You can enter only if you have a ticket.
Тек билетің болса ғана кіре аласың.
Only if — қажетті шарт.
SITUATION 8.2
Only if you study will you pass.
Тек оқысаң ғана өтесің.
Only if сөйлем басында келсе, негізгі бөлікте инверсия болады.
SITUATION 8.3
If only I had more time!
Шіркін, уақытым көбірек болса ғой!
If only — тілек, шарт емес.

Есте сақтаңыз

  • Only if пен if only сөздерінің орны ауысқанда мағынасы түбегейлі өзгереді.
  • Only if сөйлем ортасында болса, негізгі бөлікте әдетте инверсия жоқ.
Mini Quiz · ___ fire, use the stairs.
LESSON 09

Should + inversion

If сөзінсіз ресми ықтимал шарт
Should + subject + V1, main clause
SITUATION 9.1
Should you need help, call me.
Егер көмек керек болып қалса, маған хабарлас.
If you should need help дегенге балама.
SITUATION 9.2
Should anything change, we will inform you.
Бірдеңе өзгерсе, хабарлаймыз.
Ресми стиль.
SITUATION 9.3
Should he arrive early, ask him to wait.
Ерте келсе, күтуін сұра.
Should бастауыштың алдында тұрады.

Есте сақтаңыз

  • Should you will need — қате; should-тен кейін V1.
  • Бұл құрылым ықтималдығы төмен/сыпайы ресми шартта жиі кездеседі.
Mini Quiz · Should you ___ any problems, contact us.
LESSON 10

Were + inversion

Қазіргі болжамды шарт
Were + subject + complement / Were + subject + to V1
SITUATION 10.1
Were I you, I would apologize.
Мен сенің орныңда болсам, кешірім сұрар едім.
If I were you баламасы.
SITUATION 10.2
Were she here, she would understand.
Ол осында болса, түсінер еді.
Were + subject + complement.
SITUATION 10.3
Were the company to close, many people would lose their jobs.
Компания жабылатын болса, көп адам жұмыссыз қалар еді.
Were + subject + to V1.

Есте сақтаңыз

  • Were I knew — қате; were-инверсиясы тиісті were құрылымдарында қолданылады.
  • Were to көбіне болашақтағы гипотетикалық жағдайды көрсетеді.
Mini Quiz · Were he ___ earlier, we could talk.
LESSON 11

Had + inversion

Өткендегі орындалмаған шарт
Had + subject + V3, would have + V3
SITUATION 11.1
Had I known, I would have called you.
Білгенімде, саған қоңырау шалар едім.
If I had known дегенге тең.
SITUATION 11.2
Had they left earlier, they would be home now.
Ертерек шыққанда, қазір үйде болар еді.
Mixed Conditional инверсиясы.
SITUATION 11.3
Had she studied, she might have passed.
Оқығанда, емтиханнан өтуі мүмкін еді.
Might have — ықтимал өткен нәтиже.

Есте сақтаңыз

  • Had I would know — қате; had-тен кейін V3 керек.
  • Had-инверсиясы Third және Past → Present Mixed-та қолданылады.
Mini Quiz · Had they ___ sooner, they would be here now.
LESSON 12

Wish / If only: Present

Қазіргі жағдайға өкініш
Wish / If only + Past Simple (were)
SITUATION 12.1
I wish I knew the answer.
Жауапты білсем ғой.
Қазір білмейді.
SITUATION 12.2
If only I were taller!
Бойым ұзындау болса ғой!
Қазіргі шындыққа қарсы тілек.
SITUATION 12.3
She wishes she had more free time.
Бос уақыты көбірек болса екен деп тілейді.
Had — Past Simple, Past Perfect емес.

Есте сақтаңыз

  • Wish + would көбіне басқа адамның өзгеретін әрекетіне қатысты.
  • I wish I would know — әдетте қате; I wish I knew дұрыс.
Mini Quiz · I wish I ___ French.
LESSON 13

Wish / If only: Past

Өткенге өкініш
Wish / If only + had + V3
SITUATION 13.1
I wish I had listened to you.
Сені тыңдағанымда ғой.
Өткендегі істелмеген әрекет.
SITUATION 13.2
If only we had left earlier!
Ертерек шыққанымызда ғой!
Өткенге өкініш.
SITUATION 13.3
He wishes he had not spent the money.
Ақшаны жұмсамағанында ғой деп өкінеді.
Past Perfect negative.

Есте сақтаңыз

  • Wish + Past Simple қазіргі өкініш; wish + Past Perfect өткен өкініш.
Mini Quiz · I wish I ___ earlier yesterday.
LESSON 14

Wish + would / could

Өзгеріс пен мүмкіндікке тілек
Wish + would + V1; Wish + could + V1
SITUATION 14.1
I wish you would stop interrupting me.
Сөзімді бөле бермесең екен.
Басқа адамның мінез-құлқы өзгерсе деген тілек.
SITUATION 14.2
I wish it would stop raining.
Жаңбыр тоқтаса екен.
Өзгерісті күту.
SITUATION 14.3
I wish I could swim.
Жүзе алсам ғой.
Қазіргі қабілет/мүмкіндік жоқ.

Есте сақтаңыз

  • I wish I would be taller орнына I wish I were taller.
  • Would және could мағынасы бірдей емес.
Mini Quiz · I wish you ___ making that noise.
LESSON 15

Would rather / It is time / As if

Гипотетикалық қосымша құрылымдар
Would rather + subject + Past Simple; It is time + Past Simple; As if + Past Simple/Past Perfect
SITUATION 15.1
I would rather you stayed here.
Сенің осында қалғаныңды қалар едім.
Өзге адамның қазіргі/болашақ әрекетіне тілек.
SITUATION 15.2
It is time we went home.
Үйге қайтатын уақыт болды.
Past Simple формасы, қазіргі қажеттілік.
SITUATION 15.3
He talks as if he knew everything.
Ол бәрін білетіндей сөйлейді.
Шындыққа сәйкес келмеуі мүмкін.
SITUATION 15.4
She looked as if she had seen a ghost.
Ол елес көргендей көрінді.
Өткенге қатысты болжамды ұқсастық.

Есте сақтаңыз

  • Would rather + V1: I would rather stay — өз қалауым.
  • Would rather + subject + Past Simple: I would rather you stayed — басқа адамға қатысты.
  • As if + indicative нақты ықтимал жағдайларда да қолданылады: It looks as if it is going to rain.
Mini Quiz · I would rather you ___ here.
LESSON 16

Conditional traps

КТ-дағы жиі қателер
If + Present Simple, will + V1 (First Conditional)
SITUATION 16.1
If she comes tomorrow, we will start.
Ол ертең келсе, бастаймыз.
Әдеттегі First Conditional-да if-тен кейін will емес, Present Simple.
SITUATION 16.2
If you will wait here, I will check.
Осы жерде күте тұрсаңыз, тексеремін.
Will — сыпайы ниет/дайындық; бұл ерекше қолданыс.
SITUATION 16.3
Unless you study, you will fail.
Оқымасаң, құлайсың.
Unless you do not study деп шатастырмаңыз.
SITUATION 16.4
If I had worked harder, I would be happier now.
Көбірек еңбек еткенімде, қазір бақыттырақ болар едім.
Өткен себеп пен қазіргі нәтиже.

Есте сақтаңыз

  • Unless және if not айырмасын контексте тексеріңіз.
  • In case — алдын ала сақтану; if — шарт.
  • Only if — қажетті шарт; if only — өкініш.
Mini Quiz · If it ___ tomorrow, we will stay home.
LESSON 17

Suppose / Supposing / What if

Болжам мен елестетілген жағдай
Suppose / Supposing (that) + clause; What if + clause
Suppose you won a scholarship. What would you do?
Елестетші, сен грант ұтып алдың. Не істер едің?
Suppose + Past Simple: қиялдағы жағдай.
Supposing it rains tomorrow, what will we do?
Ертең жаңбыр жауса, не істейміз?
Нақты болашақ мүмкіндік: Present Simple.
What if you had missed the flight?
Ұшаққа үлгермей қалғаныңда не болар еді?
What if + Past Perfect: өткендегі балама жағдай.

Есте сақтаңыз

  • Suppose және supposing that көбіне if мағынасындағы болжамды ашады.
  • What if сұрағы салдар немесе қауіп туралы ойлануға шақырады.
  • What if I were you? — қиял; What if it rains? — нақты мүмкіндік.
Mini Quiz · ___ you won a million tenge, what would you buy?
LESSON 18

Otherwise / Or else

If сөзін қолданбай шартты білдіру
Imperative / statement + otherwise / or else + result
Hurry up, otherwise you will miss the train.
Асық, әйтпесе пойызға үлгермейсің.
Otherwise = if you do not hurry.
Study carefully, or else you may make mistakes.
Мұқият оқы, әйтпесе қателесуің мүмкін.
Or else — салдар туралы ескерту.
I did not have your number; otherwise, I would have called you.
Сенің нөмірің болмады; әйтпесе қоңырау шалар едім.
Өткенге қатысты іске аспаған нәтиже: would have + V3.

Есте сақтаңыз

  • Otherwise — «әйтпесе», көбіне алдыңғы шарт орындалмаған жағдайда болатын нәтижені көрсетеді.
  • Or else — бейресми, кейде қатаң ескерту реңкі бар.
  • Otherwise-тен кейін will, would, would have сияқты формалар уақыт пен мағынаға тәуелді.
Mini Quiz · Leave now, ___ you will be late.
LESSON 19

But for / Without

Жасырын шарт: болмаса / болмағанда
But for / Without + noun or -ing phrase
But for your help, I would have failed.
Сенің көмегің болмағанда, құлар едім.
But for your help = if you had not helped me.
Without water, plants would die.
Су болмаса, өсімдіктер өлер еді.
Without + noun, гипотетикалық нәтиже.
Without studying, she would not have passed the exam.
Дайындалмағанда, ол емтиханнан өтпес еді.
Without + -ing: әрекетке қатысты жасырын шарт.

Есте сақтаңыз

  • But for + зат есім / есімдіктің объект формасы: but for him, but for her support.
  • Without + noun / V-ing; соңынан толық if-clause міндетті емес.
  • Нәтиженің уақытына қарай would + V1 немесе would have + V3 таңдаңыз.

LESSON 20

If it weren't for / If it hadn't been for

Қазіргі және өткендегі маңызды себеп
If it were not for + noun → would + V1; If it had not been for + noun → would have + V3
If it were not for my family, I would feel lonely.
Отбасым болмаса, өзімді жалғыз сезінер едім.
Қазіргі жағдайға қарсы шарт.
If it had not been for the doctor, he would have died.
Дәрігер болмағанда, ол қайтыс болар еді.
Өткендегі іске аспаған нәтиже.
Were it not for your support, I would give up.
Қолдауың болмаса, берілер едім.
Were it not for — if сөзінсіз ресми инверсия.

Есте сақтаңыз

  • Were it not for — Second Conditional мәніндегі ресми инверсия.
  • Had it not been for — Third Conditional мәніндегі ресми инверсия.
  • Қазіргі: were not for; өткен: had not been for.

LESSON 21

Wish vs Hope

Өкініш пен шынайы үміттің айырмасы
Wish + Past Simple / Past Perfect; Hope + present / will / past (context)
I wish I spoke English fluently.
Ағылшынша еркін сөйлесем ғой.
Қазіргі шындыққа қарсы тілек.
I hope I pass the exam tomorrow.
Ертең емтиханнан өтемін деп үміттенемін.
Болашақтағы шынайы үміт.
I wish I had passed the exam.
Емтиханнан өткенімде ғой.
Өткенге өкініш.
I hope she arrived safely.
Ол аман-есен жетті деп үміттенемін.
Өткен оқиғаның нәтижесі әлі белгісіз болуы мүмкін.

Есте сақтаңыз

  • Wish + Past Simple: қазір басқаша болса деген тілек; wish + had + V3: өткенге өкініш.
  • Hope + Present Simple немесе will: шынайы болашақ үміті.
  • Hope + Past Simple: өткен оқиғаның қалай болғаны әлі белгісіз болғанда қолданылады.
  • I hope I would pass — әдеттегі болашақ үміт үшін дұрыс таңдау емес.

LESSON 22

Would rather + Past Perfect

Басқа адамның өткен әрекетіне қатысты қалау
Would rather + subject + had + V3
I would rather you had told me the truth yesterday.
Кеше маған шындықты айтқаныңды қалар едім.
Өткенде басқаша болғанын қалау.
She would rather he had not spent the money.
Ол оның ақшаны жұмсамағанын қалар еді.
Өткен әрекетке қатысты болымсыз форма.
I would rather stay home tonight.
Бүгін кешке үйде қалғанды қалар едім.
Өз әрекетім: would rather + V1.
I would rather you stayed home tonight.
Сенің бүгін кешке үйде қалғаныңды қалар едім.
Басқа адамның қазіргі/болашақ әрекеті: Past Simple.

Есте сақтаңыз

  • Өз қалауым: would rather + V1; басқа адамның қазіргі/болашақ әрекеті: would rather + subject + Past Simple.
  • Басқа адамның өткен әрекеті: would rather + subject + Past Perfect.
  • Would rather you had told ≠ would rather you told: уақыт айырмашылығы бар.

LESSON 23

It's high time / It's about time

Бір әрекетті жасау әлдеқашан қажет
It is (high/about) time + subject + Past Simple; It is time + to V1
It is high time we started preparing.
Дайындықты әлдеқашан бастауымыз керек еді.
High time — кешігіп жатқан қажеттілік.
It is about time you went to bed.
Ұйықтайтын уақытың болды.
About time + Past Simple.
It is time to leave.
Кететін уақыт болды.
It is time + to-infinitive.
It is time for the students to begin.
Студенттердің бастайтын уақыты болды.
It is time for + noun + to V1.

Есте сақтаңыз

  • High time сөйлеушінің «әлдеқашан керек еді» деген реңкін күшейтеді.
  • It is high time we go — стандартты емтихандық құрылым емес; went дұрыс.
  • It is time to go — infinitive, ал It is time we went — Past Simple.
